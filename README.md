# 3D Animated Image Background Test Site

A single-page test site that uses `get.jfif` as a clean, full-screen hero visual with CSS 3D transforms, layered image echoes, metallic light sweeps, and cursor/device-orientation parallax.

The layout keeps the uploaded image visible with `background-size: contain` instead of cropping it into abstract panels.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
